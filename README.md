CMPT 276 Group 6 Project Proposal

Web application name: Booksprint

The application will be an interactive typing app that allows you to type along a book (or
other form of text such as a PDF) while reading it. The problem of improving the ability
to type and read is currently solved by regular typing and reading sites, but this combines
both of them into one. It differentiates itself this way, and it is both educational and
entertaining. The target audience is wide, ranging from young children simply attempting
to learn both abilities, to adults looking to improve their typing while doing so in a fun
manner.

The application features many epics/main features. This includes implementing the API
(fetching books, such as from the Google Books API), persistence (user data and
progress), the typing system itself, a login system, and the design and UI. Other features
such as organization might also be included. These are big features that meet the amount
of group members we have, and may be split or shared as well. The work should be
sufficient.
